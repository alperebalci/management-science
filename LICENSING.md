# Licensing

This repository is a curated collection assembled from several specialist repositories in the same portfolio.

There is **no single repository-wide license that overrides the case-study licenses**. Each case study retains the license terms associated with its source project. The applicable license file is stored inside the corresponding case-study directory, and `SOURCE.md` records the source repository and project location.

Before reusing code from a case study, review the license in that case directory and the source repository identified in `SOURCE.md`.

This structure is intentional because the source projects do not all use identical licensing terms.

## Original flagship cases

The cases under `case-studies/flagships/` were created specifically for this repository and each carries the Jors Academy Restricted Source License v1.0 in its own `LICENSE.md` file.
